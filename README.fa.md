# Shopping List — لیست خرید

![Python](https://img.shields.io/badge/python-3.7%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

یک برنامه‌ی ساده‌ی **لیست خرید** تحت خط فرمان با پایتون که رابط فارسی داره. محصولات توی یک فایل JSON ذخیره می‌شن، پس لیستت بین اجراها پاک نمی‌شه.

> نسخه‌ی انگلیسی این فایل: [README.md](README.md)

## امکانات

- اضافه‌کردن محصول به‌همراه موجودیش
- حذف محصول (اگر وجود نداشته باشه پیام مناسب می‌ده)
- دیدن کل لیست خرید
- نمایش شماره تماس (با یه متغیر قابل تغییر)
- ذخیره‌ی خودکار لیست در `shopping_list.json` بعد از هر تغییر
- خروجی رنگی با [colorama](https://pypi.org/project/colorama/) (اگر نصب نباشه هم برنامه بدون مشکل کار می‌کنه)
- منو تا وقتی گزینه‌ی خروج (5) رو بزنی تکرار می‌شه
- مدیریت امن ورودی‌ها (با ورودی اشتباه کرش نمی‌کنه)

## نصب و اجرا

```bash
git clone https://github.com/<username>/shopping-list-app.git
cd shopping-list-app
pip install -r requirements.txt
python shopping.py
```

بعد از اجرا کلمه‌ی `open` رو بنویس تا منو باز بشه، بعد یه عدد بین ۱ تا ۵ وارد کن.

## گزینه‌های منو

| گزینه | کار |
| --- | --- |
| 1 | اضافه‌کردن محصول (نام + موجودی) |
| 2 | حذف محصول |
| 3 | دیدن همه‌ی محصولات |
| 4 | نمایش شماره تماس |
| 5 | خروج |

## ذخیره‌سازی

لیست توی فایل `shopping_list.json` کنار اسکریپت ذخیره می‌شه. این فایل خودکار ساخته می‌شه و توی `.gitignore` هست، پس داده‌ی شخصی‌ت هیچ‌وقت توی گیت آپلود نمی‌شه.

## شخصی‌سازی

شماره‌ت رو توی متغیر `PHONE` بالای فایل `shopping.py` عوض کن.
